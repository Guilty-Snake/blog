# Enumuration through Nmap
Targer machine with the ip address **10.48.159.211** was provided.

1. How many ports are open?  
[nmap insert_ip] showed 3 ports which were open.
2. What is the version of nginx?  
[namp -sV insert_ip] showed that nginx version 1.16.1 was running on http on the target.
